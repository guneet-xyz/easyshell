A range includes the marker lines themselves. You can delete them afterwards with another `sed` and the `d` command, or use `awk` with a flag that you switch on after a BEGIN line and off at an END line:

```bash
awk '/^END$/ { f = 0 } f; /^BEGIN$/ { f = 1 }' file.txt
```

(The lone `f;` prints the line whenever `f` is set. The order of the three parts is what keeps the markers out.)
