`grep` sees text, not structure: it can't tell a real `gold` key from the word `"gold"` inside a string. Let `jq` do the digging.

The recursive descent operator `..` visits every value in a JSON document, at every depth:

```bash
echo '{"a": {"b": [1, 2]}}' | jq -c '..'
```

```json
{"a":{"b":[1,2]}}
{"b":[1,2]}
[1,2]
1
2
```
