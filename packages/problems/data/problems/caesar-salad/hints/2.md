To build the shifted alphabet, write the alphabet twice and take 26 letters starting at position `k`. The shell can slice strings with `${var:offset:length}`:

```bash
A=ABCDEFGHIJKLMNOPQRSTUVWXYZABCDEFGHIJKLMNOPQRSTUVWXYZ
echo "${A:3:26}"   # DEFGHIJKLMNOPQRSTUVWXYZABC
```

Then `tr 'A-Z' "${A:3:26}"` shifts every capital letter by 3. Do the same for lowercase.
