For each shift, save the attempt (in a variable or a file in `/tmp`), then only print it if its **last** line ends with `CROUTONS!`:

```bash
tr 'A-Za-z' "..." < note.txt > /tmp/try
if tail -n 1 /tmp/try | grep -q 'CROUTONS!$'; then
  cat /tmp/try
fi
```

Shifting forward by `26 - k` undoes a shift of `k`, so trying every forward shift from 1 to 25 covers every possible key.
