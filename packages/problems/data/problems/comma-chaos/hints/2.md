One trick is to swap the commas **inside** quotes for a placeholder character that doesn't appear in the file (like `;`). After that, a plain `cut -d,` works again:

```bash
awk -F'"' -v OFS='"' '{for (i = 2; i <= NF; i += 2) gsub(/,/, ";", $i)} 1' venues.csv
```

`-v OFS='"'` puts the quotes back when `awk` rebuilds the line, and the lone `1` at the end prints every line.
