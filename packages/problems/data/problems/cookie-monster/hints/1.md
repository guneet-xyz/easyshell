Read the two lines of `login.txt` with `sed -n 1p login.txt` and `sed -n 2p login.txt`, or with `read`:

```sh
{ read -r user; read -r pass; } < login.txt
```

`curl -d` sends form data in a `POST` request, but it sends it exactly as written: a `&` in the password would start a new field. `--data-urlencode "password=$pass"` encodes the value for you.
