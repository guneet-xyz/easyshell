Start by finding the IDs of the posts to delete. `jq` can filter an array with `select`:

```sh
curl -s http://localhost:4000/posts | jq '.[] | select(.author == "Melon Usk") | .id'
```

`==` compares the whole string exactly, which is what you want here. Filters like `contains` or `test` would also match the fan club.
