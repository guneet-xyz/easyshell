`curl -X DELETE http://localhost:4000/posts/<id>` deletes one post. To run it once per ID, loop over the IDs with `for id in $(...); do ...; done`, or pipe them into `xargs`:

```sh
... | xargs -I{} curl -s -X DELETE http://localhost:4000/posts/{}
```

`-I{}` tells `xargs` to run the command once per input line, replacing `{}` with the line.
