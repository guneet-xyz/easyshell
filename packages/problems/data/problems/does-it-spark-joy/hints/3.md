`awk` and a pipeline of `sed`s can't edit a file in place by themselves. Write the result to a temporary file, then move it over the original:

```bash
awk '...' notes.md > tidy.md && mv tidy.md notes.md
```

Don't redirect straight into `notes.md` (`awk ... notes.md > notes.md`): the shell empties the file before `awk` gets to read it.
