If you `sort` the output of `md5sum`, duplicates end up next to each other, and within a group of duplicates the names are in order too (the checksum is the same, so `sort` compares the names). So in each group, the first line is the keeper and every other line is a file to delete.

`awk` can remember what it has seen: `seen[$1]++` is `0` (false) the first time a checksum shows up and non-zero (true) every time after that.
