`split("=")` splits at **every** `=`, which mangles values like `a=b==`. Either glue the rest back together with `join("=")`, or use a regex that captures everything after the first `=`:

```bash
echo 'URL=https://x.dev/?a=1' | jq -R 'capture("^(?<k>[^=]+)=(?<v>.*)$")'
```

```json
{
  "k": "URL",
  "v": "https://x.dev/?a=1"
}
```

Then build a one-key object with `{(.k): .v}`, collect them in an array, and merge them with `add`.
