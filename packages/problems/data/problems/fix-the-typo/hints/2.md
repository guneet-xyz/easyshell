Gluing the content into a JSON string by hand (`"{\"content\": \"$content\"}"`) breaks as soon as the content contains a quote or a newline. Let `jq` build the JSON for you; it escapes everything properly:

```sh
jq -c '{content}' fix.json
```

`curl -d @-` reads the request body from stdin, so you can pipe `jq`'s output straight into `curl`.
