You can build an object with a computed key by wrapping the key in parentheses, and `length` tells you how big an array is:

```bash
echo '[{"user": "Dave"}, {"user": "Dave"}]' | jq -c '{(.[0].user): length}'
```

```json
{ "Dave": 2 }
```

Adding objects together with `add` merges them into one. Careful: `add` on an empty array gives `null`, and `//` lets you pick a fallback value.
