`awk` can read several files in one go, and it has associative arrays: you can store a value under any key and look it up later.

```bash
awk -F, '{ name[$1] = $2 } END { print name["2"] }' customers.csv
```

When `awk` reads two files, `NR` (the line number across all files) is equal to `FNR` (the line number in the current file) only while it's reading the first file. `FNR == 1` is the header line of each file.
