A common `awk` pattern for joining two files:

```bash
awk -F, 'FNR == 1 {next} NR == FNR {name[$1] = $2; next} {total[$2] += $3} END {...}' customers.csv orders.csv
```

- the first block skips both header lines;
- the second block only runs for `customers.csv` and remembers each name;
- the third block only runs for `orders.csv` and adds up the amounts per customer.

In the `END` block, loop over the totals with `for (c in total)` and print them with `printf "%s,%.2f\n"`.
