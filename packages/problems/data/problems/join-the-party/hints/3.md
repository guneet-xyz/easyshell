`awk`'s `for (key in array)` loop comes out in no particular order, so sort the result afterwards. `sort` can sort by several keys: `-t,` splits fields at commas, `-k2,2nr` sorts by the second field numerically in reverse, and a second `-k1,1` breaks ties by the name:

```bash
... | sort -t, -k2,2nr -k1,1
```
