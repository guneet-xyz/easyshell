Loop over the reversed recipe and use `case` to pick the right command for each layer. Keep the current state of the message in a file and replace it after every layer:

```bash
cp message.txt /tmp/cake
for step in $(tac recipe.txt); do
  case $step in
    base64) base64 -d /tmp/cake > /tmp/layer ;;
    rev) ... ;;
  esac
  mv /tmp/layer /tmp/cake
done
cat /tmp/cake
```
