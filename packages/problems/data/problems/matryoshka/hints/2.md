You don't know how many layers there are, so you can't write the steps out one by one. Repeat until the secret shows up:

```bash
while [ ! -f secret.txt ]; do
  # peel one layer
done
```

To pick the right tool for a layer, match its name against patterns with `case`. The first matching pattern wins, so put the longer ones (`*.tar.gz`) before the shorter ones (`*.gz`):

```bash
case "$name" in
  *.tar.gz) echo "a gzipped tarball" ;;
  *.gz) echo "just gzipped" ;;
esac
```
