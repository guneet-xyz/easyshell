How do you know the name of the next layer? One trick: if you delete each layer once it's unpacked, there's only ever one file in the directory, so `$(ls)` is the current layer.

```bash
while [ ! -f secret.txt ]; do
  f=$(ls)
  case "$f" in
    *.tar.gz) tar -xzf "$f" && rm "$f" ;;
    *.zip) unzip -q "$f" && rm "$f" ;;
    *.gz) gunzip "$f" ;;
    # ... and the rest of the formats
  esac
done
cat secret.txt
```
