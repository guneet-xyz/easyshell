You don't know in advance how many pages there are, so you need a loop that keeps going until there's nothing left. In `sh`, that's a `while` loop:

```sh
page=1
while [ "$page" != null ]; do
  echo "visiting page $page"
  page=...
done
```

`jq .next` prints the next page number, or `null` when there is no next page.
