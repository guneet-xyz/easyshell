Inside the loop, you need the response twice: once for the posts and once for `next`. Save it in a variable (or a file) so you only request each page once:

```sh
response=$(curl -s "http://localhost:4000/posts?page=$page")
echo "$response" | jq '.posts[] | select(.author == "The Strokes")'
page=$(echo "$response" | jq .next)
```
