Start with the header. `cut` extracts a column, `sort -u` sorts it and removes duplicates, and `paste -sd, -` joins lines with commas:

```bash
tail -n +2 scores.csv | cut -d, -f2 | sort -u | paste -sd, -
```

You can save that in a variable with `subjects=$(...)` and pass it into `awk` with `-v subjects="$subjects"`.
