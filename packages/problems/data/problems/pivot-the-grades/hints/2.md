`awk` arrays can have composite keys, so you can remember every score by student **and** subject:

```bash
awk -F, 'NR > 1 { score[$1 "," $2] = $3 } END { print score["Dave,Soups"] }' scores.csv
```

Use `(key in score)` to check whether a score exists. Don't just test `score[key]`: a score of `0` is false in `awk`.
