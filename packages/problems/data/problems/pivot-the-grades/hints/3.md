BusyBox `awk` can't sort, so let `sort -u` produce the sorted student list and feed it to `awk` as a second "file" (`-` means standard input). While `awk` reads `scores.csv` it remembers the scores, and for each student line it prints a row:

```bash
subjects=$(tail -n +2 scores.csv | cut -d, -f2 | sort -u | paste -sd, -)
tail -n +2 scores.csv | cut -d, -f1 | sort -u | awk -F, -v subjects="$subjects" '
  NR == FNR { if (FNR > 1) score[$1 FS $2] = $3; next }
  FNR == 1 { n = split(subjects, s, ","); printf "student"; for (i = 1; i <= n; i++) printf ",%s", s[i]; print "" }
  { printf "%s", $0; for (i = 1; i <= n; i++) { k = $0 FS s[i]; printf ",%s", (k in score) ? score[k] : "-" }; print "" }
' scores.csv -
```
