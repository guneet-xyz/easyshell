`curl` can print details about the transfer after it's done with `-w` (`--write-out`). It understands variables like `%{http_code}`:

```sh
curl -s -o /dev/null -w '%{http_code}' https://example.com
```

Alternatively, `curl -sI` sends a `HEAD` request and prints only the response headers. The status code is the second word on the first line.
