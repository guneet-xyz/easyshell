To pipe the output of several commands into one, group them with braces (mind the spaces and the last `;`):

```bash
{ cat access.log; zcat access.log.*.gz; } | wc -l
```

`cat` complains about files that don't exist; `2>/dev/null` hides the complaint. A `for` loop over `access.log*` with a `case` on the file name works too.
