A `for` loop can visit every entry in a folder, and `[ -f "$f" ]` checks whether an entry is a regular file (and not a folder):

```bash
for f in downloads/*; do
  [ -f "$f" ] && echo "$f is a file"
done
```

Careful: `*` doesn't match names that start with a dot. `.*` does, but it also matches `.` and `..`, which are folders.
