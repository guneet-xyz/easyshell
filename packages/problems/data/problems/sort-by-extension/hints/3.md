A `case` statement can tell files with an extension from those without. The pattern `?*.*` needs a dot that is **not** the first character, so it matches `cat.jpg` and `.secret-plans.txt` but not `untitled` or `.DS_Store`:

```bash
case "$f" in
  ?*.*) echo "has an extension" ;;
  *) echo "goes to misc" ;;
esac
```

`mkdir -p` creates a folder and doesn't complain if it already exists.
