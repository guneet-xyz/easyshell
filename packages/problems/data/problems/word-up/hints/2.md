`tr` can turn everything that is **not** a letter into a newline. `-c` takes the complement of the first set, and `-s` squeezes runs of newlines into one:

```bash
tr -cs 'A-Za-z' '\n' < shakespeare.txt
```

If the file starts with a non-letter, you get one empty line at the top: `grep -v '^$'` drops it. (`grep -oE '[A-Za-z]+'` is another way to get one word per line.)
